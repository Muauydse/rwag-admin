=====================================================
             لوحة تحكم رواج — للمالك وفريق العمل
=====================================================

⚠️ هام جداً
   • هذا المجلد للمالك فقط ولا علاقة له بالنظام الذي يُسلَّم للعملاء.
   • عند توزيع النظام على العملاء انسخ مجلد البرنامج «بدون» مجلد «لوحة التحكم».
   • الملفات الخاصة كلها في مجلد منفصل بجانب هذا المجلد: «لوحة التحكم - ملفات خاصة»
       keys\        مفتاح التوقيع الخاص (من يملكه يستطيع إصدار تفعيلات) ومفتاح التشفير
       panel-data\  بيانات اللوحة والعملاء، العقود، النسخ الاحتياطية، إعداد MongoDB
       بيانات الدخول، أسرار الاستضافة
     لا ترفعه ولا ترسله لأحد أبداً. احتفظ بنسخة منه في مكان آمن (فلاشة مشفرة) —
     إذا ضاع مفتاح التوقيع لن تقبل الأنظمة الموزّعة رموزاً جديدة.
   • مجلد «لوحة التحكم» نفسه كله كود فقط ويمكن رفعه إلى GitHub بأمان.

▶ التشغيل
   «تشغيل لوحة التحكم.bat» ← يفتح http://127.0.0.1:8788/

   • تغيير البريد: الإعدادات والحساب (للمالك فقط).

▶ الأقسام
   الرئيسية .............. مؤشرات، نشاط الأجهزة، توزيع الباقات، اشتراكات تنتهي قريباً
   الأجهزة والمشتركون ..... كل جهاز: بيانات المنشأة، الاستخدام، المستخدمون، التذاكر، الأعطال، النسخ
   طلبات فتح الحسابات .... طلبات «اشترك الآن» من النظام: بيانات العميل والمنشأة والباقة والخصم.
                            • زر واتساب: تختار ما يُرفق بالرسالة (تعريف، مزايا، أمان البيانات، خدمة العملاء،
                              أسعار الباقات، طرق الدفع...) وتعدّلها ثم تفتح محادثة العميل مباشرة.
                            • «قبول»: ينشئ الحساب برقم الجوال + يفعّل الباقة + يرسل بيانات المنشأة للنظام
                              + ينشئ عقد اشتراك PDF احترافي (السعر، المنشأة، اسم المستخدم وكلمة المرور،
                              الضمان وخدمة العملاء، التوقيع والختم) — تنزيل أو إرسال للعميل عبر واتساب.
   الباقات وأكواد الخصم ... إضافة/تعديل الباقات (الاسم، المدة، السعر، المزايا، مميزة) وأكواد الخصم
                            (نسبة أو مبلغ، عدد مرات، تاريخ انتهاء، باقات محددة).
   الموقع والزوار ......... إحصائيات الموقع: متصل الآن، الزوار والزيارات، العائدون، الدول والمدن، المصادر
                            (Google، واتساب، سناب...)، الأجهزة والمتصفحات، الأقسام الأكثر مشاهدة، ساعات الذروة،
                            مسار التحويل (زيارة ← الباقات ← فتح الاشتراك ← طلب)، التحميلات، وتفاصيل كل زيارة
                            مع تصدير Excel. ومن «إعدادات الموقع»: رابط التحميل، الإصدار، النصوص، الأقسام، الإعلان.
   الصيانة والإعلانات ..... وضع صيانة للنظام (يوقف النظام لدى العملاء المتصلين) ووضع صيانة للموقع،
                            مع رسالة ووقت العودة، وشريط إعلان داخل النظام وأعلى الموقع.
   حسابات العملاء ......... أضف عميلاً برقم جواله وكلمة مرور وفعّل اشتراكه مباشرة — يدخل بها للنظام.
                            عرض كلمة المرور وتغييرها، عدد الأجهزة المسموح، وإعداد نشاطه التجاري
                            من اللوحة (يصله تلقائياً ولا يُطلب منه معالج الإعداد).
   الاشتراكات والتفعيل .... تفعيل شهري/ربع سنوي/سنوي/دائم/مدة مخصصة/إيقاف + إصدار رمز تفعيل يدوي
                            (يصل للعميل تلقائياً عند المزامنة، أو أرسل الرمز عبر واتساب)
   مبيعات الاشتراكات ...... أسعار الباقات (تظهر للعملاء في النظام) + سجل كل تفعيل بمبلغه وطريقة الدفع
                            + مبيعات الشهر والإجمالي وغير المحصّل + تصدير Excel
   الدعم الفني ............ رسائل العملاء مع الصور واسم المستخدم ورقمه — الرد يظهر في إشعارات النظام
   الأعطال ................ أخطاء النظام لدى العملاء تُرسل تلقائياً
   الإشعارات .............. إرسال إشعار لكل الأجهزة أو لأجهزة محددة
   تحديثات النظام ......... رفع ملف تحديث + رقم الإصدار — يظهر «تحديث متوفر» لدى العملاء
   النسخ الاحتياطية ....... آخر نسخة لكل عميل (يومياً) — تنزيل
   الأجهزة ← الاستخدام .... مستخدمو نظام العميل وتغيير كلمة مرور أي منهم (تُرسل مشفّرة)،
                            وزر «إعداد النشاط التجاري» للجهاز
   الأجهزة ← «خروج عن بعد» ينهي جلسة الدخول على جهاز مفقود أو لموظف غادر.
   فريق العمل ............. حسابات للموظفين بصلاحيات محددة (إدارة الموظفين والإعدادات للمالك فقط)
   سجل العمليات ........... كل ما يتم في اللوحة

▶ الرسائل والعقد
   الإعدادات والحساب ← «رسالة العملاء وطرق الدفع وعقد الاشتراك»: نص كل قسم في رسالة الواتساب،
   طرق الدفع، بيانات البنك، بيانات مزود الخدمة، التعريف والضمان والشروط، صورة التوقيع والختم
   (اختياري — يُرسم ختم تلقائي)، ومعاينة العقد.
   ملاحظة: واتساب لا يسمح بإرفاق ملف عبر الرابط — نزّل العقد ثم اسحبه لمحادثة العميل.
   توليد PDF يتطلب Microsoft Edge على جهاز اللوحة.

▶ قاعدة البيانات السحابية (MongoDB)
   الإعدادات والحساب ← «قاعدة البيانات السحابية (MongoDB)»: الصق رابط الاتصال ← «اختبار الاتصال» ← «حفظ وتفعيل الربط».
   • قاعدة فارغة: تُرفع بيانات اللوحة الحالية تلقائياً. قاعدة فيها بيانات: تختار «استخدام بيانات MongoDB» أو «رفع بيانات اللوحة».
   • بعد التفعيل: MongoDB هي المصدر الرئيسي، وكل تعديل يُرفع في الخلفية خلال ثوانٍ (التغييرات فقط).
   • عند انقطاع الاتصال تعمل اللوحة بالنسخة المحلية وترفع التغييرات تلقائياً عند عودته.
   • الرابط محفوظ مشفّراً في «لوحة التحكم - ملفات خاصة»\panel-data\mongo.json ولا يُرسل أبداً للنظام أو الموقع.
   • يتطلب مكتبة pymongo (مثبتة):  python -m pip install pymongo
   • في Atlas: أضف عنوان IP جهاز/خادم اللوحة في Network Access.

▶ النسخ الاحتياطي للوحة
   الإعدادات والحساب ← نسخة تلقائية يومياً (آخر 10 نسخ ZIP تشمل البيانات ومفاتيح التوقيع)
   مع اختيار مجلد الحفظ (فلاشة / OneDrive / قرص آخر) ونسخة فورية وتنزيل.

▶ النقل للإنترنت لاحقاً
   حالياً تعمل اللوحة على هذا الجهاز، والنظام لدى العملاء يتصل بالعنوان http://127.0.0.1:8788
   (أي أنها تعمل فقط للأنظمة المثبتة على نفس الجهاز).
   للتشغيل أونلاين:
     1) ارفع هذا المجلد على خادم (VPS) وشغّل panel_server.py خلف HTTPS
        (اضبط المتغير RAWAJ_PANEL_HOST=0.0.0.0).
     2) غيّر «عنوان خادم الدعم والتفعيل» في إعدادات النظام ← الاشتراك والاتصال
        (أو القيمة cloudUrl في الملف %USERPROFILE%\Rawaj\config.json لدى العميل).
   أو استبدل طبقة التخزين بـ Firebase (Firestore + Authentication + Cloud Functions لتوقيع التراخيص)
   مع الإبقاء على نفس واجهات /api/client/* — النظام لا يحتاج أي تعديل آخر.

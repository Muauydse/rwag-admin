# لوحة تحكم رواج لإدارة الأعمال

لوحة إدارة نظام **رواج**: الأجهزة والاشتراكات، حسابات العملاء، طلبات فتح الحسابات، عقود PDF، مبيعات الاشتراكات، الدعم الفني، الأعطال، الإشعارات، التحديثات، الموقع والزوار، الصيانة والإعلانات — مع تخزين سحابي في **MongoDB**.

> ⚠️ **الأسرار لا تُرفع إلى GitHub أبداً**: مفتاح توقيع التراخيص، مفتاح التشفير، بيانات العملاء، وملفات كلمات المرور محفوظة في مجلد منفصل **«لوحة التحكم - ملفات خاصة»** بجانب مجلد اللوحة وليس داخله، فمجلد اللوحة كله كود يمكن رفعه بأمان. ومع ذلك القواعد في `.gitignore` وفحص «نشر على GitHub.bat» باقية كاحتياط.
> يُنصح بجعل المستودع **Private**.

---

## 1) الرفع إلى GitHub
1. أنشئ مستودعاً جديداً **Private** من [github.com/new](https://github.com/new) (بدون README).
2. شغّل **`نشر على GitHub.bat`** والصق رابط المستودع عند الطلب.
3. لاحقاً: كلما عدّلت اللوحة شغّل نفس الملف لرفع التحديثات.

## 2) قاعدة البيانات (MongoDB Atlas) — إجباري للاستضافة
قرص الاستضافة مؤقت ويُمسح عند كل نشر، لذلك يجب أن تكون البيانات في MongoDB:
1. على جهازك: لوحة التحكم ← الإعدادات ← **قاعدة البيانات السحابية (MongoDB)** ← الصق الرابط ← «حفظ وتفعيل الربط» (تُرفع بياناتك الحالية).
2. في Atlas ← **Network Access** ← أضف `0.0.0.0/0` (لأن عنوان الاستضافة متغير).

## 3) تجهيز الأسرار
شغّل **`تجهيز أسرار الاستضافة.bat`** ← ينشئ ملف `أسرار-الاستضافة.txt` داخل مجلد «لوحة التحكم - ملفات خاصة» فيه:

| المتغير | الوصف |
|---|---|
| `RAWAJ_SIGNING_KEY` | مفتاح توقيع التراخيص — **نفس المفتاح** وإلا ترفض أنظمة العملاء رموز التفعيل |
| `RAWAJ_SECRET_KEY` | مفتاح تشفير كلمات مرور حسابات العملاء |
| `MONGODB_URI` | رابط MongoDB Atlas |
| `MONGODB_DB` | اسم قاعدة البيانات (افتراضياً `rawaj`) |

## 4) النشر على Render
1. [render.com](https://render.com) ← **New** ← **Blueprint** ← اختر مستودع GitHub (يقرأ `render.yaml` تلقائياً).
2. أدخل قيم المتغيرات من ملف الأسرار ← **Apply**.
3. بعد اكتمال النشر يظهر رابط مثل `https://rawaj-panel.onrender.com` — ادخل بنفس بريد وكلمة مرور المالك.

> الخطة المجانية تنام بعد 15 دقيقة خمول (أول طلب بعدها يتأخر ~50 ثانية). للاستخدام الفعلي اختر **Starter**.
> بديل: أي استضافة تدعم Docker (Railway, Fly.io, VPS) — الصورة جاهزة في `Dockerfile`.

## 5) ربط النظام والموقع باللوحة الأونلاين
- **النظام** لدى كل عميل: الإعدادات ← الاشتراك والاتصال ← «عنوان خادم الدعم والتفعيل» = رابط Render.
  (أو عدّل `cloudUrl` الافتراضي في `server.py` قبل توزيع النظام على العملاء).
- **الموقع**: في `موقع رواج/config.js` ضع `PANEL_URL: 'https://rawaj-panel.onrender.com'`.

## ملاحظات
- ملفات الرفع (صور التذاكر، ملفات التحديث، عقود PDF، نسخ العملاء) تُحفظ أيضاً في MongoDB (GridFS — مجموعة `files`) وتُستعاد تلقائياً لقرص الاستضافة عند كل تشغيل، فلا حاجة لقرص دائم.
- التشغيل محلياً كما هو: `تشغيل لوحة التحكم.bat`.
